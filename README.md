# Älska Älvdalen — webbplats

Statisk sajt (ren HTML/CSS/JS, inget byggsteg), byggd mobil-först efter
`Alska_Grafisk_manual_2015.pdf` och mötet 26 oktober 2026. Hostas på GitHub
Pages (`CNAME` = alskaalvdalen.com).

## Sidor

- `index.html` — Hem: tre ingångar (flytta hit, se och göra, boende)
- `se-och-gora.html` — Aktiviteter, sevärt, evenemang
- `flytta-hit.html` — Varför flytta hit, jobb, driva eget, skolor
- `boende.html` — Hyra, köpa/bygga, prova på
- `om-alvdalen.html` — Byarna runt Älvdalen och kulturen
- `alska-alvdalen.html` — Föreningen: vision, idéråd, magasin, Creativet
- `kontakt.html` — Kontakt, medlemskap (diskret), formulär (mailto)
- `om.html` — Omdirigering till `alska-alvdalen.html`

## Varumärke

Färger, typsnitt och formspråk ligger som designtokens överst i
`assets/css/style.css` (färgerna är de exakta ur manualens avsnitt 3.1).
Ropa Soft Pro ligger som fontfiler i `assets/fonts/`; brödtexten använder
EB Garamond som stand-in tills Garamond Premier Pro finns. Se
`assets/fonts/README.md`.

## Att tänka på

- **Bilder:** hero- och sektionsbilderna är beskurna ur föreningens egna
  bilder så att den inbakade loggan inte syns. Videon är borttagen.
- **Evenemang:** länkar till Visit Dalarnas kalender för Älvdalen
  (`visitdalarna.se/alvdalen/evenemang`). Ingen live-koppling än — Visit
  Dalarna erbjuder ingen känd inbäddning, se action item för Hannah.
- **Innehåll som återstår:** intervjuer med inflyttade, boendeinformation
  (hyresvärdar, mäklare, avstånd), byarna, skolor/förskolor och film.
- **Medlemskap och kostnad** läggs till senare; tills vidare hänvisas till
  kontaktsidan.
